# МИР Печати — сайт

Одностраничный сайт копицентра «МИР Печати» (Снежногорск, ул. Павла Стеблина, 16).
Чистый HTML/CSS/JS, без сборки: файлы можно залить на любой хостинг как есть.

**Сайт:** https://ldsaf23fdewfdsf.github.io/mir-pechati/ (GitHub Pages, бесплатно).
Обновить сайт: изменить файлы, затем `git add -A && git commit -m "..." && git push`. Через 1–2 минуты изменения появятся онлайн.

```
index.html    — разметка и тексты
styles.css    — оформление
script.js     — меню, «открыто/закрыто», отзывы, анимации + НАСТРОЙКИ вверху файла
favicon.svg   — иконка вкладки
PROMPT-site.md — разбор wowpassport.ru и промт (только локально, в git не попадает)
```

## Посмотреть локально

```bash
python3 -m http.server 4321
```

Открыть http://localhost:4321

## Выложить в интернет

Подойдёт любой статический хостинг: Timeweb, Beget, REG.RU (загрузить файлы в `public_html`),
или бесплатно GitHub Pages / Netlify. Домен вида `mirpechati-snezh.ru` подключается в панели хостинга.

## Отзывы

Сейчас работают бесплатно и без регистрации:

- **Яндекс Карты**: официальный виджет Яндекса, отзывы подтягиваются сами (id организации `25478937082`).
- **2ГИС**: у 2ГИС нет бесплатного виджета отзывов, поэтому показана карточка с рейтингом
  и кнопками «Читать отзывы» / «Оставить отзыв».

### Единая лента Яндекс + 2ГИС, как у ВауПаспорт

ВауПаспорт использует платный сервис **MyReviews** (myreviews.ru, есть 7 дней бесплатно).
Чтобы включить такой же виджет:

1. Зарегистрироваться на myreviews.ru и добавить филиал.
2. Вставить ссылки на карточки:
   - Яндекс: https://yandex.ru/maps/org/mir_pechati/25478937082/
   - 2ГИС: https://2gis.ru/snezhnogorsk/firm/70000001083035959
3. Создать виджет типа «Блок», в коде установки найти `uuid:"…"` и `name:"…"`.
4. Вписать их в начало `script.js`:
   ```js
   const MYREVIEWS = { uuid: 'ваш-uuid', name: 'ваш-name' };
   ```
   Вкладки исчезнут, вместо них появится общая лента. Если виджет не загрузится, вкладки вернутся сами.

Цифры рейтинга в плашках (4,9 / 40 оценок и 5,0 / 11 оценок) вписаны вручную в `index.html`.
Их нужно иногда обновлять.
